# Plantillas de correo de Supabase Auth

Generadas con `npx tsx scripts/gen-auth-templates.ts`. Se pegan en Supabase → Authentication → Emails (Templates): el **Subject** y el **Message body** (HTML).

- `confirmar-cuenta.html` — Subject: **Confirma tu cuenta · Pulso**
- `invitacion.html` — Subject: **Te invitaron a Pulso**
- `enlace-magico.html` — Subject: **Tu enlace para entrar a Pulso**
- `restablecer-contrasena.html` — Subject: **Restablece tu contraseña de Pulso**
- `cambio-de-correo.html` — Subject: **Confirma tu nuevo correo en Pulso**
- `reautenticacion.html` — Subject: **Tu código de seguridad de Pulso**
